# Proyecto · Clase 2 · Iván necesita ideas de publicaciones que sí pueda usar esta semana

**LIA Lab · DEV.F · Módulo 2 (Prompting)**
**Rol: Iván (Marketing de Tostadores del Valle) · Tiempo estimado: ~30 min**

Caso: Iván es el único de marketing en Tostadores del Valle, una marca de café de especialidad.
Pide "ideas para publicaciones" y recibe una lista genérica que no le sirve. Esta entrega
muestra cómo hacer la conversación de la manera correcta: prompt con las cuatro partes,
segunda vuelta puntual, verificación contra la ficha por asistente y plantilla reutilizable.

## Cómo saber si quedó bien (checklist del brief)

- [x] El prompt tiene las cuatro partes señalizadas: **rol, tarea, contexto y formato**.
- [x] El formato pide algo que Iván pueda usar tal cual: **cantidad de ideas, para qué día y qué lleva cada una**.
- [x] El contexto usa **datos de la ficha** de la empresa (no frases generales) e incluye las **restricciones de la marca**.
- [x] La segunda vuelta dice **qué cambiar y por qué**, sin empezar de cero, y deja claro **qué no se debe tocar**.
- [x] La revisión nombra **al menos una cosa concreta** que se comparó contra la ficha (una idea, una cifra o una promesa) y qué se hizo con ella.
- [x] La plantilla **se puede usar la siguiente semana cambiando solo lo que está entre corchetes**.

## Restricciones firmes de la marca (de la ficha)

1. No hay descuentos ni promociones (la de octubre terminó el viernes pasado).
2. No se promete envío en 24 horas: el envío tarda de 2 a 3 días hábiles.
3. No se usan fotos de personas.
4. No se afirma nada que no esté en la ficha (premios, cifras de visitas o de ventas).
5. Tono: cercano y sencillo. Sin tecnicismos de cata y sin exceso de signos de exclamación.

**Material usado:** Ficha de Tostadores del Valle (anexada al brief del proyecto) + los 5 resultados
que recibió Iván con un prompt genérico ("dame ideas para publicaciones").
